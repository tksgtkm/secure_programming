# ハイパーバイザーとは
仮想マシン(VM)を作成・実行・制御するための機能を提供するソフトウェアやファームウェアを指す。
ハイパーバイザーはハードウェア上で直接動作するType-1ハイパーバイザと他のOS上で動作するType-2ハイパーバイザに分類される。

今回はKVMを利用してLinux上で動くType-2ハイパーを作る。

# KVMの概要
KVMはLinuxにおいて仮想化技術を使うためのカーネルモジュール

## ゲストプログラム
VM上で動かすプログラムを作成する。
QEMUなどのハイパーバイザーを使う場合、VM上で動かすプログラムにあたるのは
LinuxやWindowsのようなOSになるが、今回はカウントダウンするだけのプログラムを動かす。
ただし、OSのない環境(ベアメタル)で動くプログラムにする必要がある。
ここではシリアルポートから整数を受取り、その整数をカウントダウンしてシリアルポートに出力する
アセンブリコードを作る。
countdown.s

## KVMの動作の概要
KVM_CREATE_VMでVMを作成し、KVM_CREATE_VCPU、KVM_GET_VCPU_MMAP_SIZEなどで起動するVMの設定を行った後に、KVM_RUNでVMを実行する流れになる。
